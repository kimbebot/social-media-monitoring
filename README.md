# 🕵️ Social Media Monitor

A stealthy, production-ready social media monitoring system that scrapes posts from LinkedIn, Facebook, Twitter, and other platforms with **maximum undetectability**.

## 🎯 Features

- **Maximum Stealth**: Advanced anti-detection techniques
  - Browser fingerprint randomization
  - Human-like behavior simulation (typing, scrolling, mouse movement)
  - Session persistence and cookie management
  - Randomized delays and timing
  - Real browser profiles
  
- **Multi-Platform Support**
  - ✅ LinkedIn (implemented)
  - 🔄 Facebook (template ready)
  - 🔄 Twitter/X (template ready)
  
- **Robust Architecture**
  - Async/await for high performance
  - SQLite/PostgreSQL database support
  - Encrypted credential storage
  - Comprehensive error handling
  - Detailed logging
  
- **Smart Scraping**
  - Only scrapes new posts (no duplicates)
  - Incremental updates
  - Engagement metrics tracking
  - Media attachment support

## 📋 Requirements

- Python 3.8+
- Playwright (for browser automation)
- PostgreSQL or SQLite

### Run Scheduled Monitoring

```python
import asyncio
from apscheduler.schedulers.asyncio import AsyncIOScheduler
from main import SocialMediaMonitor

async def scheduled_scraping():
    monitor = SocialMediaMonitor()
    await monitor.initialize()
    
    scheduler = AsyncIOScheduler()
    
    # Run every 3 hours
    scheduler.add_job(
        monitor.run_all_scrapers,
        'interval',
        hours=3,
        id='scraper_job'
    )
    
    scheduler.start()
    
    # Keep running
    while True:
        await asyncio.sleep(60)

asyncio.run(scheduled_scraping())
```

### Query Scraped Data

```python
import asyncio
from src.database.db_manager import db
from sqlalchemy import select
from src.database.models import Post

async def get_recent_posts():
    await db.init_db()
    
    async with db.get_session() as session:
        result = await session.execute(
            select(Post)
            .order_by(Post.posted_at.desc())
            .limit(10)
        )
        posts = result.scalars().all()
        
        for post in posts:
            print(f"{post.author_name}: {post.content[:100]}...")

asyncio.run(get_recent_posts())
```

## 🔧 Troubleshooting

### Login Fails

- LinkedIn uses security challenges (CAPTCHA, 2FA)
- Solution: Login manually first with non-headless mode
- Use `HEADLESS=false` in .env during first login
- Session will be saved for future use

### Posts Not Being Saved

- Check database connection
- Verify post selectors haven't changed
- Check logs in `logs/social_monitor.log`

### Session Expired

- Delete session files in `browser_profiles/`
- Re-login will create new session
